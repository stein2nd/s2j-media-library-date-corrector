# S2J MediaLibrary Date Corrector - ブロック仕様

## 初期リリース

初期リリースでは、Gutenberg ブロックもショートコードも作りません。Classic エディター用のスクリプトも、フロント用のバンドルも作りません。

日付の補正は、メディアライブラリの一覧 (`upload.php`) で行います。スクリプトは `admin_enqueue_scripts` で、その画面の場合だけ読みます。ビルド対象は `admin` だけです。

`register_block_type` は呼びません。設定画面は、ブロックとは別に「設定」メニューへ置きます。詳細は [管理画面 UI 仕様](./admin_ui_spec.md) です。

属性、CTA、ライブラリへの案内は、初期リリースの契約ではありません。

## 後から足す場合

ブロックが必要になった場合、`block.json` と `gutenberg` のビルド対象を追加します。`frontend` バンドルは、`viewScript` が必要になった場合だけです。
